## Cách dùng

- Phiên nhận task đọc file task, rồi đọc các tài liệu được nêu trong mục "Đọc trước".
- Làm xong một mục thì đánh dấu `[x]` và ghi ngắn kết quả (PR, artboard) ngay dưới mục đó, trong cùng PR.
- Gặp điểm chưa rõ thì ghi vào mục "Câu hỏi mở" của task, không tự đoán.
- Task xong hết thì đổi **Trạng thái** ở đầu file thành `Xong` và cập nhật bảng dưới đây.
